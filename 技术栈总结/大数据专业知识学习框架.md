### *pyspark*
- 让spark支持python，避免java或者scala等等JVM环境，简单易学，更加直观，集成py的框架和库，numpy和pandas，类似于echarts的py版本pycharts，
- spark on YARN模式，py环境，RDD，
- shuffle，sparksql，dataframe，dataset，YARN，
- 分析数据，

-     from pyshark import SparkContext
      sc = SparkContext("local", "app")
      rdd = sc.parallelize([1,2,3])

-     from pyspark.sql import SparkSession
      spark = SparkSession.builder.appName("Test").getOrCreate()
      df = spark.read.csv(...)
      rdd = spark.sparkContext.parallelize([1,2,3])
  
>SparkContext 是 Spark 早期入口，用于操作 RDD 底层 API，无查询优化器；
SparkSession 是 Spark2.0 之后统一的入口，封装了 SparkContext，支持 DataFrame、Dataset 和 SparkSQL，内置 Catalyst 优化器，适合结构化数据处理，是目前推荐使用的 API。
